🛡️ ZeroSus — AI-Powered Fake Internship Offer Detector

ZeroSus is a web-based security awareness platform that helps students identify potentially fake or fraudulent internship offers received through email and SMS.

It analyzes offer messages, detects suspicious indicators, generates a risk score, and provides safety recommendations. It also includes a Placement Cell dashboard for reviewing reports and sharing verified warnings.

⚙️ Installation

1. Clone the repository

git clone https://github.com/VeeraPatel7/ZeroSus-Fake-Internship-Offer-Detector.git

2. Open the project

cd ZeroSus-Fake-Internship-Offer-Detector

3. Configure the API

Create a local config.js file using config.example.js as a reference.

Never put a real API key inside config.example.js or commit it to GitHub.

4. Run the project

Open index.html in your browser, or use VS Code Live Server.

🔐 Security

Never commit API keys or passwords.

Keep config.js inside .gitignore.

Use placeholder values in config.example.js.

Revoke and replace any API key that has accidentally been exposed.

🌟 Why ZeroSus?

Students receive internship opportunities through emails, SMS, messaging platforms, and social media. Fraudulent offers may use attractive salaries, urgent deadlines, fake company details, or suspicious links.

ZeroSus provides a simple first-level safety check before students trust or respond to an offer.
